# Assembling the keyboard

This document describes how to put the keyboard together once you have the PCB, case, and firmware, available in the [Releases](https://github.com/ilauzon/mica-keyboard/releases) section.

## Bill of materials

## Equipment
- Soldering iron & solder
- Screwdriver
- Patience

## Instructions
1. Solder the components to the PCB.
2. Plug the key switches into the board.
3. Screw the front plate, PCB and case together via the mounting holes.
4. Flash each half of keyboard.
